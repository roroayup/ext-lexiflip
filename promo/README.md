# Materi promosi Lexiflip

Semua gambar dan video diambil dari Lexiflip 1.1.0 yang benar-benar berjalan di Microsoft Edge.
Artikel di dalamnya ("BluePlanet Journal", ditulis "Maya Hartono") adalah artikel contoh fiktif.
Arti dan definisi di dek contoh diisi rapi lebih dulu supaya hasilnya konsisten. Hasilnya sama
dengan yang Lexiflip tampilkan saat mencari arti otomatis.

## Video

| File | Ukuran | Durasi | Dipakai di |
| --- | --- | --- | --- |
| `video/lexiflip-promo-1080p.mp4` | 1920×1080 | ±48 detik | YouTube, lalu tautannya ditempel di kolom *Promo video* Chrome Web Store / Edge Add-ons; juga untuk LinkedIn dan website |
| `video/lexiflip-promo-vertical-1080x1920.mp4` | 1080×1920 | ±48 detik | Instagram Reels, TikTok, YouTube Shorts |

Isi video:
1. Blok kata → popover arti → Tambah.
2. Belajar di widget pojok layar.
3. Blok paragraf → pilih kata.
4. Upload PDF.
5. Halaman belajar.

Video **tanpa suara**. Tambahkan musik bebas royalti (misalnya dari YouTube Audio Library atau
pustaka musik TikTok/Instagram) saat mengunggah.

Chrome Web Store dan Edge Add-ons hanya menerima video promosi berupa **tautan YouTube**, bukan
file. Unggah dulu ke YouTube (boleh *Unlisted*), lalu tempel tautannya.
